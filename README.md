# Учи Тропарь - Инструкция по запуску

Это современное веб-приложение, которое требует сборки и сервера для работы.

## 🚀 Как запустить на GitHub Pages (РЕКОМЕНДУЕТСЯ)

1. Создайте репозиторий на GitHub с названием `Uchi_Tropar`.
2. Загрузите в него все файлы из этого архива.
3. Перейдите в **Settings -> Pages**.
4. **КРИТИЧНО:** В пункте **Build and deployment -> Source** выберите **"GitHub Actions"** (не "Deploy from branch").
5. Перейдите во вкладку **Actions**, дождитесь зеленой галочки.
6. Сайт будет доступен по адресу: `https://ваше-имя.github.io/Uchi_Tropar/`

## 💻 Как запустить локально на компьютере
Если вы просто откроете `index.html` двойным кликом, страница будет **ПУСТОЙ** — это защита браузера. Для работы нужно:

1. Установите [Node.js](https://nodejs.org/).
2. Откройте папку с проектом в терминале.
3. Введите команды:
   ```bash
   npm install
   npm run dev
   ```
4. Откройте адрес `http://localhost:3000`, который появится в терминале.

---
### Почему страница пустая на GitHub?
Если вы видите пустую страницу, откройте консоль браузера (F12). Скорее всего, там ошибки 404.
*   Убедитесь, что в `vite.config.ts` в строке `base` указано название вашего репозитория: `base: '/Uchi_Tropar/'`.
*   Убедитесь, что вы выбрали **GitHub Actions** в настройках Pages.
