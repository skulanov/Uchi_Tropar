# 📖 Учи Тропарь

Интерактивное веб-приложение для изучения и запоминания православных богослужебных песнопений: воскресных тропарей и кондаков восьми гласов Октоиха, а также тропарей и кондаков двунадесятых праздников.

🔗 **Онлайн-версия**: [skulanov.github.io/Uchi_Tropar](https://skulanov.github.io/Uchi_Tropar/)

---

## ✨ Возможности

### 1. Канонические тексты песнопений
* **Воскресные тропари (1–8 гласы)** — тексты с ударениями, расстановкой смысловых колен (`/`) и встроенным аудиопроигрывателем напевов.
* **Воскресные кондаки (1–8 гласы)** — полные тексты кондаков Октоиха для каждого гласа.
* **Двунадесятые праздники** — тропари и праздничные кондаки всех 12 великих праздников с удобным раздельным изучением каждого текста.

### 2. Интеллектуальный режим заучивания («Учить»)
Для каждого тропаря и кондака доступна ступенчатая система тренировки памяти (5 уровней сложности):
* **Уровень 0 (Чтение)** — открытый текст с ударениями и разделителями.
* **Уровень 1 (Начальный)** — скрыто каждое третье слово.
* **Уровень 2 (Средний)** — скрыто каждое второе слово.
* **Уровень 3 (Опорные буквы)** — отображаются только первые буквы каждого слова (остальные буквы заменены точками). Идеально для тренировки темпа чтения по памяти.
* **Уровень 4 (Наизусть)** — весь текст скрыт интерактивными плашками. При наведении мыши или касании пальцем на смартфоне всплывает подсказка со скрытым словом.

### 3. Режим «Случайный выбор» (Экзамен / Самопроверка)
* Случайная выборка любого песнопения из всего корпуса текстов без повторов в течение одной сессии.
* Вход в режим сразу на максимальном уровне сложности (текст скрыт).
* Обратная прокрутка подсказок (4 → 3 → 2 → 1 → 0) по мере необходимости вспомнить текст.

### 4. Встроенный плеер
* Минималистичный аудиоплеер с напевами воскресных тропарей и праздников, индикатором прогресса и поддержкой мобильных устройств.

### 5. Дизайн и эргономика
* Тёплая литургическая палитра, вдохновлённая старинными богослужебными книгами.
* Классическая акцидентная типографика с засечками (serif), крупный удобочитаемый шрифт.
* Плавные анимации переходов между карточками и режимами.
* Полная адаптивность: комфортно учить как на смартфоне, так и на планшете или компьютере.

## 🚀 Локальный запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/skulanov/Uchi_Tropar.git
   cd Uchi_Tropar
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

3. **Запустите локальный сервер разработки**:
   ```bash
   npm run dev
   ```
   Откройте появившуюся в консоли ссылку (обычно `http://localhost:3000`).

4. **Сборка для продакшена**:
   ```bash
   npm run build
   ```
   Собранные оптимизированные статические файлы появятся в директории `dist/`.

## 🌐 Развёртывание на GitHub Pages

Проект настроен на автоматическую сборку и развёртывание через **GitHub Actions**:
1. При любом `git push` в ветку `main` запускается воркфлоу `.github/workflows/deploy.yml`.
2. В репозитории в разделе **Settings → Pages** в пункте **Source** должно быть выбрано **GitHub Actions**.
3. Сборка и публикация происходят автоматически за 1–2 минуты.
